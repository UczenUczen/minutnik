# Minutnik wstecz

## Analiza promptu

Oryginalny prompt z demonstracji nie jest dostępny, dlatego poniższa lista jest jego odtworzeniem na podstawie siedmiu wymagań zadania.

### Odtworzony prompt i klasyfikacja

1. Zbuduj aplikację minutnika do pracy i odpoczynku. — **Co zbudować**
2. Minutnik ma odliczać 25 minut pracy i 5 minut przerwy. — **Co zbudować**
3. Po zakończeniu pracy program ma automatycznie rozpocząć przerwę. — **Co zbudować**
4. Program ma pokazywać liczbę ukończonych cykli. — **Co zbudować**
5. Użytkownik ma móc zmieniać czas pracy i przerwy w oknie programu. — **Co zbudować**
6. Interfejs ma być po polsku, nazwy w kodzie po angielsku, a program nie może używać dodatkowych bibliotek. — **Jak zbudować**
7. Czas ma być wyświetlany w formacie mm:ss. — **Jak poznać, że gotowe**

### Podsumowanie klasyfikacji

- Co zbudować: **5**
- Jak zbudować: **1**
- Jak poznać, że gotowe: **1**

Najmniej reprezentowana jest kategoria „Jak poznać, że gotowe”, ponieważ prompt zawiera niewiele jednoznacznych kryteriów sprawdzających poprawność działania programu.

## Decyzja dotycząca licznika cykli

Po naciśnięciu przycisku Reset podczas przerwy licznik ukończonych cykli zostaje wyzerowany. Sprawdziłem działanie programu i obecnie zachowuje się on właśnie w ten sposób.

To była decyzja **modelu**, a nie użytkownika.
